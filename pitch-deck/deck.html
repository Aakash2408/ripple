Ripple 1

The Problem

API changes break things.
Fixing them takes days.

  • Engineer changes user.proto — removes a field
  • 5 downstream services break silently
  • 2-3 days of Slack pinging to coordinate fixes
  • 3-6 engineers involved per propagation event
  • 2-4 packages touched manually

This happens every week at every company with microservices.

Ripple 3

How It Works

Detect → Find → Fix → PR

1. Detect

Custom diff engines for 10 contract types. Understands semantics — not just text diff.

2. Find Consumers

Ensemble of 5 strategies: grep + imports + git history + playbooks + multi-invoker.

3. Fix + PR

Template-based or LLM-powered fix generation. Opens PR with explanation.
