How it works

01

Detect

Parses 10 contract types (OpenAPI, Proto, GraphQL, DB, AsyncAPI, Avro, tRPC, Thrift, JSON Schema, Smithy). Finds every breaking change in the diff.

02

Find

Ensemble consumer finder with 5 detection channels: code search, git history learning, playbooks, multi-invoker analysis, and custom rules. Finds consumers you didn't know existed.

03

Fix

Generates idiomatic fixes in 12 languages with AI confidence scoring. Template engine for speed, LLM fallback for edge cases.

04

Ship

Opens fix PRs with Impact Reports, lifecycle labels, and upstream status tracking. Notifies via Slack. CI/CD gate blocks merge until consumers are safe.
