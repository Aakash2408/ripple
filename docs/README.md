# Ripple Documentation

**Ripple** automatically detects breaking API changes, finds every downstream consumer, generates fixes in their language, and opens pull requests — across 7 platforms and 12+ programming languages.

## What Ripple Does

1. You push a breaking change to a backend service
2. Ripple detects it (supports 10 contract types)
3. Finds all downstream consumers automatically
4. Generates code fixes in their language
5. Opens PRs with AI confidence scores and impact reports
